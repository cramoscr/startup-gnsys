# Product Mindset — Our Compass

These principles are inspired by the **3Pillar Global Product Mindset** and are kept deliberately short.

They are not intended to become another heavy methodology. They are our compass when product development takes us far enough from shore that implementation pressure, attractive features, technical enthusiasm, or uncertainty can make us lose direction.

## Core Principles

### 1. Minimize Time to Value

Deliver useful value as early as possible. Do not wait for the entire envisioned system to exist before a real user can benefit.

### 2. Excel at Change

Assume that learning will change the product. Favor decisions, architecture, and ways of working that allow us to adapt rather than defend yesterday's assumptions.

### 3. Build for Outcomes

Success is not measured by features completed or code produced. It is measured by meaningful outcomes for users and the business.

### 4. Solve for Need

Start with the real need or problem. Features, technologies, interfaces, and implementation choices come afterward.

---

## How we use this

When we are unsure what to build next, these four questions bring us back on course:

1. **What value can reach the user sooner?**
2. **What have we learned that should change our direction?**
3. **What outcome are we actually trying to produce?**
4. **What real need are we solving?**

> This is a compass, not a map.
