# Startup GnSys

A working laboratory for discovering, challenging, validating, and developing business and software-product ideas.

Startup GnSys is not a repository for collecting ideas indefinitely. Its purpose is to help convert intuition into evidence and evidence into decisions.

## Core Process

**Idea → Hypothesis → Evidence → Economics → Small Experiment → Market Reaction → Decision**

Possible decisions include:

- **GO** — evidence justifies further investment.
- **ITERATE** — promising, but assumptions need refinement or another experiment.
- **PARK** — potentially useful, but not worth pursuing now.
- **KILL** — evidence does not justify further investment.

## Operating Principle

> Ideas are cheap. Evidence earns investment.

We should not build something merely because we can build it.

Before substantial technical investment, we should understand the problem, the potential customer, alternatives, willingness to pay, plausible economics, and the cheapest useful way to test the critical assumptions.

## Collaboration

This laboratory combines human experience, intuition, domain knowledge, and judgment with AI-assisted research, analysis, modeling, technical exploration, and constructive criticism.

The AI's role is not to automatically validate an idea. It should challenge assumptions, search for contradictory evidence, quantify where possible, propose alternatives, and help design experiments that expose ideas to reality.

See [`principles/working-agreement.md`](principles/working-agreement.md) for the working agreement behind this approach.

## Repository Evolution

The repository will remain deliberately lightweight. New folders, processes, and templates should appear only when real work creates a need for them.

Ideas that survive validation and become actual products may eventually move into their own dedicated repositories.
